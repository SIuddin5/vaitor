Data Source

Real library and academic data used to train and evaluate the recommendation system.

How the data was collected

For the project “Online Book Recommendation Using Collaborative Filtering”, the team first searched for suitable global public datasets. When those were not sufficient for the research goals, they approached the university library.

With the help of the honorable department head, real transaction data was obtained from the university library system. Two main types of book circulation data were collected, along with student CGPA information used for research analysis.
